CODERSWURLD PRINT HELPER
========================

Prints receipts straight to your receipt printer (Xprinter and other ESC/POS
printers), with no print window.

SET UP (once per till computer)
1. Right-click this zip file and choose "Extract All".
2. Open the extracted folder and double-click "Install Print Helper.bat".
   If Windows shows "Windows protected your PC", click "More info", then
   "Run anyway". It is a plain script you can open in Notepad to read.
3. In Coderswurld, open Printer and scanner, press "Check again", choose your
   printer and press "Print test receipt".
4. Chrome may ask to let coderswurld.com access devices on your network.
   Click Allow. That is the helper on this computer.

The helper starts by itself every time Windows starts.

IF NOTHING PRINTS
- Double-click "Start Print Helper (show window).bat" to see any error.
- In Windows Settings > Printers, check the printer is not Offline or Paused,
  and clear any stuck documents in its queue.

TO REMOVE IT
- Double-click "Uninstall Print Helper.bat".
